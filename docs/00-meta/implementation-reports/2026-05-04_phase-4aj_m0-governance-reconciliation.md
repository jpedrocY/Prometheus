## 2. Triggering Context

### 2.A Why this reconciliation exists now

After Phase 4ai's `NOT_SUPPORTED` verdict, the project record
contains four distinct streams of negative or null evidence relevant
to the discovery and admissibility layers of the research process:

1. **Six terminal strategy rejections** along structurally distinct
   axes (R2 cost-fragility; F1 catastrophic-floor; D1-A
   mechanism / framework mismatch; V2 design-stage incompatibility;
   G1 regime-gate-meets-setup intersection sparseness; C1 fires-
   and-loses contraction anti-validation).
2. **A descriptive substrate-feasibility ranking with no directional
   implication** (Phase 4ae): cost-cushion ranking
   `SOL > ADA > XRP > ETH > BTC` exists, but no symbol dominates and
   no directional edge is implied.
3. **A descriptive regime-continuity / directional-persistence null**
   (Phase 4af): post-expansion same-direction follow-through ≤ 0.50
   on every tested cell; bar-level sign persistence near random;
   trend conditioning provides no cost-adjusted directional
   advantage.
4. **A descriptive cross-sectional ranking null** (Phase 4ai):
   predeclared composite ranking on the five-symbol Phase 4ac core
   universe returned `frac_selected > median ≈ 0.49`, median
   `selected − median` spread ≤ 0 bps, Spearman IC median = 0.0 in
   every primary cell. Verdict: `NOT_SUPPORTED`.

### 2.B What Phase 4z observed about the discovery and admissibility layer

Phase 4z's central observation was that the project's research
process is **procedurally sound** at every executed layer
(authorization / branch isolation; predeclaration discipline;
forbidden-input enforcement; cost realism; PBO / DSR / CSCV
discipline; negative-baseline framework; opportunity-rate floors;
mechanism-check framework; consolidation-memo discipline) but is
**substantively under-constrained at the candidate-discovery and
hypothesis-admissibility layer**.

In particular:

- The Phase 4m 18-requirement validity gate filters for "is this
  candidate a hidden rescue?" and "is the candidate operationally
  implementable?" but does **not** require a predeclared
  baseline-superiority theory derived from theoretical content,
  does not require a design-family-distance declaration, and does
  not separate edge-rate viability from opportunity-rate viability.
- The Phase 4t 10-dimension scoring matrix evaluates
  *post-discovery* candidates against ten qualitative dimensions
  but does not impose an *upstream* admissibility test that a
  candidate must clear before scoring.
- Phase 4z therefore proposed a 32-item enriched admissibility
  framework (the existing 18 + 9 new items) **and** a
  proposed M0–M7 mechanism-check series with M0 specifically as
  a "theoretical-admissibility gate upstream of strategy-spec".
- Phase 4z left all of this as recommendations only and explicitly
  declined to adopt it as binding governance.

### 2.C What Phase 4ag did with M0

Phase 4ag, as a docs-only mechanism-source triage memo, proposed a

framework — it is the upstream admissibility screen, not a full
restatement of every Phase 4m / 4t requirement plus every Phase 4z

Phase 4ag did not adopt M0 as binding governance.

### 2.D What Phase 4ah and Phase 4ai did with M0

- **Phase 4ah** (docs-only single-position cross-sectional trend

## 5. Original Phase 4ag M0 Gate

The Phase 4ag mechanism-source triage memo recorded a ten-clause M0
mechanism-admissibility gate as a Phase 4ag-only recommendation. The
ten clauses are restated here verbatim from `Phase 4ag §6`:

1. **Mechanism source.** State the mechanism source in non-price-only
   or cross-sectional terms unless a specific theoretical reason
   exists to continue price-only.
2. **Baseline-superiority theory.** State why the candidate would
   beat R3 / H0, and why it is not a relabeled variant of R2 / F1 /
   D1-A / V2 / G1 / C1.
3. **Cost realism.** State the cost-realism plausibility under
   §11.6 = 8 bps HIGH per side (round-trip = 16 bps).
4. **Opportunity-rate plausibility.** State the predeclared
   minimum joint-trigger arrival rate per Phase 4u / 4v precedent.
5. **Design-family distance.** State distance from each of the six
   prior rejections, including the closest-prior-failure
   comparison (Phase 4z A31 analogue).
6. **Data feasibility.** State which Phase 4ac / Phase 4i / v002
   datasets are required and whether they are PASS or governed-
   PARTIAL under Phase 4ad / Phase 4j §11.
7. **Governance compatibility.** State conformance with §1.7.3,
   Phase 3r §8, Phase 3v §8, Phase 3w §6 / §7 / §8, Phase 4j §11.
8. **Forbidden-rescue check.** State explicitly that the candidate
   does not silently reduce to a prior failed strategy.
9. **Falsification criterion.** State what would falsify the
   mechanism *before* backtesting — i.e. what descriptive
   feasibility evidence would kill the candidate without spending
   backtest grid budget.
10. **Non-authorization.** State that passing M0 does **not**
    authorize a strategy-spec memo, a backtest-plan memo, a
    backtest, or any successor phase.

Phase 4ag did **not** adopt M0 as binding governance. Phase 4aj
preserves that adoption status.

### 6.A Phase 4ag M0 covers most of the Phase 4z M0 spirit

Phase 4ag's clause-2 ("baseline-superiority theory") and clause-9
("falsification criterion *before* backtesting") together capture
the substantive content of Phase 4z's M0 clause: a predeclared
theoretical statement of why the candidate should beat an
unconditioned baseline plus a predeclared falsification criterion.

Phase 4ag's clause-5 captures Phase 4z's A5 / A31
(design-family-distance and closest-prior-failure comparison).

Phase 4ag's clause-8 captures the spirit of Phase 4z's
five-rule no-rescue enforcement language.

### 6.B Phase 4ag M0 omits one Phase 4z lesson explicitly

Phase 4z's most novel addition — **opportunity-rate viability and
edge-rate viability as two separate gates** — is *not* explicit in
Phase 4ag's M0. Phase 4ag clause-4 covers opportunity-rate but does
not name edge-rate as a distinct admissibility predicate.

This is the central C1 lesson: C1 satisfied the opportunity-rate
gate (rate 3.33; 100% pass; 149 trades) and failed the edge-rate
gate (M1 −0.244R CI strictly negative). Phase 4ai is informative
here too: the cross-sectional lane satisfies opportunity-rate
viability trivially (ranking always produces an answer when not
filtered to NO_SYMBOL) but failed the edge-rate gate at the
descriptive forward-behavior layer.

A revised M0 should make this distinction explicit.

### 6.C Phase 4ag M0 is lighter than Phase 4z by design

Phase 4ag M0 is intentionally a small upstream gate. It is **not**
a full discovery method, **not** a full strategy-spec template,
**not** a full backtest-plan template, and **not** a full
execution-report template. Phase 4z proposed all four; M0 is one
fragment of the larger Phase 4z proposal.

### 6.D Conclusion: M0 is one operationalized fragment of Phase 4z

The cleanest reconciliation is:

- **Phase 4ag M0** = lightweight pre-hypothesis admissibility screen
  (the upstream filter that decides whether a candidate is even
  worth scoring against the Phase 4t matrix).
- **Phase 4z 32-item framework** = full discovery / strategy-spec /
  backtest-plan / execution-report redesign, of which M0 is one
  upstream fragment.
- **Phase 4m 18-requirement gate** = the existing binding-style
  validity gate (preserved verbatim by every memo since Phase 4m).
- **Phase 4t 10-dimension matrix** = the existing post-discovery
  scoring tool used inside discovery memos (per Phase 4n / 4t).

M0 (in either Phase 4ag or revised form) does **not** conflict with
Phase 4z; it is a strict subset of the Phase 4z proposal that could
be adopted on its own without committing to the rest.

- **validation methodology** (A25 / A26 / A27 / A28),
- **stage discipline** (A29 / A30).

### 7.C What the Phase 4m gate does *not* cover

The Phase 4m gate does **not** explicitly require:

- a *predeclared baseline-superiority theory* deriving Δ_R from
  theoretical content (Phase 4z A10 / A12 / Phase 4ag M0 clause-2),
- a *design-family declaration* with explicit distance from each
  prior rejection (Phase 4z A5 / A31 / Phase 4ag M0 clause-5),
- a *predeclared expected failure mode* (Phase 4z A13 / Phase 4ag
  M0 clause-9 falsification flavor),
- a *remain-paused-comparison* (Phase 4z A32),
- explicit *opportunity-rate / edge-rate separation* (Phase 4z
  observation; Phase 4ag M0 clause-4 covers opportunity-rate but
  not edge-rate).

### 7.D Phase 4t — 10-dimension scoring matrix

Phase 4t's scoring matrix is the project's discovery-method tool.
Its ten dimensions (`D1` through `D10`) evaluate post-discovery
candidates qualitatively:

- D1: New-theory strength
- D2: Distance from forbidden rescue
- D3: Opportunity-rate viability
- D4: Co-design clarity (V2 / G1 lessons)
- D5: Data feasibility (existing only)
- D6: Cost-survival plausibility (§11.6)
- D7: Mechanism-check designability
- D8: Governance compatibility
- D9: Implementation complexity later
- D10: Research value

### 7.E What the Phase 4t matrix covers

The Phase 4t matrix is a **per-candidate ranking tool inside a
discovery memo**, used after candidates have been named. It is
*not* an admissibility test.

### 7.F What the Phase 4t matrix does *not* cover

The Phase 4t matrix:

- does not decide whether a candidate is *admissible* upstream of
  scoring,
- does not require a baseline-superiority theory or a predicted
  Δ_R,
- does not separate opportunity-rate from edge-rate,
- does not require a remain-paused-comparison.

### 7.G How M0 relates to Phase 4m / 4t

- **Phase 4m gate** = post-discovery, pre-spec validity check. Bound
  to a *named* candidate.
- **Phase 4t matrix** = per-candidate qualitative scoring tool
  inside a discovery memo. Bound to *multiple* candidates.
- **M0 (Phase 4ag form, lightweight)** = pre-discovery
  *admissibility screen*. Bound to a *single* candidate at
  proposal time, asking "is this candidate worth scoring at all?"

These three layers are complementary, not competing. Adoption of M0
would not require amending the Phase 4m gate or the Phase 4t matrix.

### 7.H Conservative reconciliation result

```text
M0 (in Phase 4ag form, optionally revised per Phase 4aj §8) is a
useful upstream admissibility screen that complements but does not
replace the Phase 4m 18-requirement gate or the Phase 4t
10-dimension scoring matrix. It should remain recommendation-only
unless a separately authorized governance-adoption phase is chosen
by the operator.
```

## 8. Proposed Revised M0 Gate

Phase 4aj proposes a **revised** twelve-clause M0 gate that
incorporates the central Phase 4ai lesson (descriptive null) and
the central C1 lesson (opportunity-rate ≠ edge-rate). The revised
gate is **stricter** than Phase 4ag's original ten-clause version
and is closer in substance to Phase 4z's proposed M0–M7 framework.

The revised gate remains a **recommendation only**. Phase 4aj does
**not** adopt this gate as binding governance.

### 8.A Revised M0 — twelve clauses (recommendation only)

1. **Mechanism source.** State the mechanism source. If price-only
   on a tested substrate, the proposal must explicitly justify why
   it is not within the depleted price-only single-symbol
   continuation lane (Phase 4ag Family 1).
2. **Non-price-only or structurally distinct source requirement.**
   The mechanism source must be non-price-only or, if price-only,
   structurally distinct from the depleted lane (e.g., cross-symbol
   ranking with novel descriptors that are not derived from
   Phase 4ai forensic results; cross-timeframe shaping that is not
   a relabeled G1 gate).
3. **Baseline-superiority theory versus H0 and R3.** State, in
   theoretical terms, why the candidate's primary condition should
   produce positive expectancy *versus* an unconditioned baseline
   that shares the same geometry. Derive a predicted Δ_R from the
   theoretical content. Commit to the predicted Δ_R as the
   *expected outcome* of any future M1 / M2 baseline test.
4. **Rejection-topology distance.** State explicit distance from
   each of the six prior rejections (R2 / F1 / D1-A / V2 / G1 / C1)
   plus any future rejected strategies. Identify the closest-prior-
   failure trap and explain why the candidate is not that trap.
5. **Cost-realism plausibility under §11.6.** State the cost-
   realism plausibility under §11.6 = 8 bps HIGH per side
   (round-trip = 16 bps). State predicted gross expectancy and
   expected cost burden.
6. **Opportunity-rate plausibility.** State the predeclared minimum
   candidate-event arrival rate, joint-trigger arrival rate, and
   per-OOS-window trade-count floor. Derive opportunity-rate floors
   from theoretical content; do **not** derive them from prior
   failure forensic numbers.
7. **Edge-rate plausibility (NEW vs Phase 4ag M0).** State the
   predeclared minimum baseline differential the candidate is
   *expected* to produce versus the closest unconditioned baseline,
   independent of opportunity-rate. State the predicted bootstrap
   CI lower bound for that differential. Phase 4z observed (and
   the C1 / Phase 4ai sequence confirmed) that opportunity-rate
   viability is necessary but not sufficient.
8. **Data availability and integrity feasibility.** State which
   datasets are required. State whether each is `research_eligible`
   PASS or governed-PARTIAL (Phase 4ad Rule A / B / C, Phase 4j
   §11). No new acquisition implied.
9. **Governance compatibility.** State explicit conformance with:
   §11.6, §1.7.3 (0.25% / 2× / one-position / mark-price stops),
   Phase 3r §8, Phase 3v §8, Phase 3w §6 / §7 / §8, Phase 4j §11
   (if metrics OI used), Phase 4k methodology, Phase 4p / 4q / 4v
   / 4w precedents (if backtest later authorized).
10. **Forbidden-rescue and anti-reduction check.** State explicitly
    that the candidate does not silently reduce to:
    - V2 / V2-prime / V2-narrow / V2-relaxed / V2 hybrid,
    - G1 / G1-prime / G1-narrow / G1-extension / G1 hybrid,
    - C1 / C1-prime / C1-extension / C1 hybrid,
    - R2 / R1a / R1b-narrow rescue,
    - F1 mean-reversion rescue,
    - D1-A funding-trigger rescue,
    - rank-then-V2 / G1 / C1 breakout under a wrapper,
    - multi-position portfolio trading,
    - 5m strategy / hybrid / variant,
    - any prior strategy alt-symbol rerun.
11. **Pre-backtest falsification criteria.** State what descriptive
    feasibility evidence would kill the candidate *before*
    backtest grid budget is spent. The criterion must be

## 9. Proposed Post-Null Cooldown Rule

Phase 4aj proposes a specific cooldown / anti-churn rule that any
future research lane should respect after a predeclared feasibility
phase returns `NOT_SUPPORTED`.

### 9.A Post-null cooldown rule (proposed; recommendation only)

```text
After a predeclared feasibility phase returns NOT_SUPPORTED, the
same mechanism family may not be re-opened through:

  - parameter tweaks,
  - descriptor tweaks,
  - threshold tweaks,
  - symbol-universe expansions,
  - interval changes,
  - forward-horizon changes,
  - rank-quality-filter relaxations,
  - composite-weight reassignments,
  - rebalance-frequency changes,
  - or any other adjustment of the predeclared specification,

unless a future docs-only memo first identifies a materially new
mechanism source that is independent of the failed descriptor
family. Materially new means: derived from external theory or
external evidence, not from observation of the failed phase's
forensic results.

The cooldown applies to the family, not only to the specific
candidate. Reopening requires a fresh upstream M0-style memo and
separate operator authorization.
```

### 9.B Application to Phase 4ai

Applying the proposed rule to the cross-sectional ranking family
specifically:

| Action                                                                             | Status                          |
| ---------------------------------------------------------------------------------- | ------------------------------- |
| Re-running Phase 4ai with different rank-lookback windows                           | NOT recommended (rule active)   |
| Expanding the universe to BNB / DOGE / LINK / AVAX                                  | NOT recommended (rule active)   |
| Relaxing the rank-quality filter (e.g., dropping the positive 24h+72h gate)        | NOT recommended (rule active)   |
| Changing composite weights from 0.7 / 0.3                                           | NOT recommended (rule active)   |
| Changing forward horizons from 24h / 72h                                            | NOT recommended (rule active)   |
| Changing the rebalance frequency                                                    | NOT recommended (rule active)   |
| Multi-position conversion                                                           | FORBIDDEN (Phase 4ag / 4ah)     |
| Rank-then-V2 / G1 / C1 breakout reduction                                           | FORBIDDEN (Phase 4ah / 4ai)    |
| Cross-sectional lane reopening with materially new mechanism source                | conditional only; future memo  |

The cooldown does **not** mean the cross-sectional family is
permanently retired. It means the family cannot be re-opened by
post-hoc tuning of the descriptors that just failed.

### 9.C Why a cooldown rule matters

Without a cooldown rule, the natural next move after a feasibility
null is to ask "what if we tweak the descriptors / filter /
horizon?" — exactly the methodologically prohibited pattern the
six rejection topology was supposed to defend against. The cooldown
rule formalizes the defense at the family level.

### 9.D Adoption status

The cooldown rule is a **Phase 4aj recommendation only**. Phase 4aj
does not adopt it as binding governance.

### 11.A No immediate Phase 4ak research lane is recommended

adopting (or explicitly declining) the proposed admissibility
redesigns would likely repeat the V2 / G1 / C1 pattern. Phase 4ai

Per the proposed Phase 4aj §9 cooldown rule, the cross-sectional
ranking family is not eligible for descriptor-tweak re-opening. A
future cross-sectional memo would have to identify a materially
new mechanism source (external theory or external evidence), not
re-tune the Phase 4ai descriptors.

### 11.D Derivatives-context lane remains high D1-A rescue risk

Phase 4ag / Phase 4ah / Phase 4ai all marked the derivatives-
context lane as `CONDITIONAL_ONLY` with high D1-A rescue risk.
Phase 4ai's null does not strengthen that lane; if anything, it
weakens the case for opening any lane now.

### 11.E Microstructure remains complex and expensive

Phase 4ag rated microstructure / order-flow `NOT_RECOMMENDED` at
this boundary. Phase 4ai does not change that assessment. The
data-burden / cost-realism profile remains unfavorable.

### 11.F Price-only continuation remains depleted

Six terminal rejections (R2 / F1 / D1-A / V2 / G1 / C1) plus the
Phase 4af bar-level persistence null plus the Phase 4ai cross-
sectional null leave price-only single-symbol continuation
substantively depleted. Any future return to this lane requires a
fundamentally new theoretical premise, not a parameter tweak.

### 11.G The most useful next step is governance formalization, not new market research

If the operator wants further forward motion, the most procedurally
sound next step is governance formalization — i.e., a separately
authorized phase that decides whether to adopt M0 (Option B) or a
broader framework (Option C) — not a new market-research lane.

### 11.H Remain paused remains procedurally valid

Remain paused (Option D) remains the binding governance posture
when no validated strategy candidate exists, as it has since the
post-Phase 4y boundary.
